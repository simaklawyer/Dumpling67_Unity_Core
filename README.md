# Dumpling67 — Unity Core (HANDOFF)

Код-пакет миграции на Unity. **Начни с [HANDOFF.md](HANDOFF.md).**

## Импорт

1. Unity **2022.3 LTS / 6**, шаблон **URP**
2. Скопируй `Assets/Dumpling67` и `Assets/WebGLTemplates` в проект
3. Пустая сцена → GO + `SceneBootstrap` → Play (мгновенный тестовый уровень)
4. Либо ручная сборка по `docs/THIRD_PERSON_SETUP.md`

## Главное

- **Third-person** (Roblox-like) — основной режим
- Гача / 2D-runner / softbody — вспомогательные системы
- Площадки: Telegram / Яндекс / VK (мосты + jslib)
- WebGL template: TMA + Yandex SDK hooks
