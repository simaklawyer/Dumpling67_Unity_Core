# _Frozen2D — заморожено

Вторичные системы (2D softbody-режим, раннер) отделены от активной разработки:
не подключены к `GameManager`/third-person ядру, ничего в остальном коде на них
не ссылается — перенос сюда ничего не сломал.

**Причина:** third-person (Roblox-like) — подтверждённый приоритет геймплея
(см. HANDOFF.md, п.1 и п.12). Держать обе ветки одновременно живыми — лишняя
нагрузка на арт/баланс на этой стадии.

**Если понадобится вернуть:** просто верните файлы в `../Gameplay/`, уберите
шапку-предупреждение из каждого файла — компиляция не пострадает, зависимостей
не было.
